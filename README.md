# Work Tracker

A small Flask app for tracking check-ins and check-outs with a dark modern UI. The app saves work session data to `worklog.xlsx`, displays flash messages, and schedules a reminder based on the latest end time.

## Features

- `GET /checkin` renders the check-in form
- `POST /checkin` saves check-in data and starts a reminder thread
- `GET /checkout` renders the check-out form and summary panel
- `POST /checkout` saves check-out data and computes hours worked + overtime
- Saves all submissions to `worklog.xlsx`
- Optional desktop notification support via `plyer`

## How it works

1. User opens `/checkin` and submits:
   - date (defaults to today)
   - start time
   - expected end time
   - the app saves this entry to `worklog.xlsx`
   - a reminder thread reads the latest expected end time and schedules a notification 15 minutes before

2. User opens `/checkout` and submits:
   - date (defaults to today)
   - actual check-out time
   - the app saves this entry to `worklog.xlsx`
   - it then looks for the latest matching check-in record on the same date
   - computes total hours worked
   - computes overtime relative to the expected end time
   - displays the results in hours and minutes

## Files

- `app.py` — main Flask application and route logic
- `templates/checkin.html` — dark-themed check-in page
- `templates/checkout.html` — dark-themed check-out page with summary panel
- `worklog.xlsx` — stored work log data file generated by the app

## Requirements

- Python 3.10+ (tested with Python 3.11)
- Flask
- pandas
- plyer (optional for desktop notifications)

## Installation

1. Create and activate a virtual environment:

```bash
python -m venv .venv
.\.venv\Scripts\activate
```

2. Install dependencies:

```bash
pip install flask pandas plyer
```

## Run the app

```bash
python app.py
```

Then open one of these in your browser:

- `http://127.0.0.1:5000/checkin`
- `http://127.0.0.1:5000/checkout`

## Notes

- The app stores all entries in `worklog.xlsx` in the project directory.
- Flash messages confirm successful check-in and check-out.
- If `plyer` is unavailable, reminders print to the terminal.

## Customization

- Change the Flask secret key in `app.py` before deploying.
- Modify `templates/checkin.html` and `templates/checkout.html` to adjust form fields or styling.
